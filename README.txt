# Om Pawar Portfolio

A responsive personal portfolio website for Om Pawar, BSc Computer Science Student.

## Files
- `index.html` - complete portfolio content
- `style.css` - responsive styling
- `script.js` - mobile navigation, scroll animations, active navigation

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize
Search in `index.html` to replace/add:
- Email
- GitHub / LinkedIn
- University name
- Actual projects
- Project links
- Profile photo

The current version intentionally describes several technologies as learning areas rather than professional experience.
